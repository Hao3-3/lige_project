========================================
  泉城智慧出行项目 - GitHub 上传方法
========================================

项目已在本地完成 Git 初始化并提交（95 个文件），
以下两种方法任选其一即可上传到 GitHub。

========================================
方法一：GitHub Desktop（推荐，国内网络更稳）
========================================

1. 打开 GitHub Desktop
2. 点左上角 "File" → "Add Local Repository"
   （或主界面点 "Add an Existing Repository from your local drive..."）
3. 选择项目文件夹：
   D:\internship\济南智慧出行\济南智慧出行
4. 添加后，GitHub Desktop 会显示已提交的内容
5. 点顶部蓝色按钮 "Publish repository"
6. 在弹窗中：
   - Name：填仓库名（如 jinan-smart-travel）
   - Owner：选你的 GitHub 账号
   - 可勾选 "Keep this code private" 设为私有
   - 点 "Publish Repository"
7. 等待上传完成，完成后可在 GitHub 网页看到代码

========================================
方法二：Git 命令行（网络能直连 GitHub 时用）
========================================

1. 先在 GitHub 网页创建一个空仓库（不要勾选初始化 README）
2. 打开 PowerShell 或 CMD，执行：

   cd "D:\internship\济南智慧出行\济南智慧出行"
   git remote add origin https://github.com/你的用户名/仓库名.git
   git branch -M main
   git push -u origin main

3. 如果提示登录，用 GitHub 账号授权即可

========================================
注意事项
========================================

1. .env 文件（含 mapbox token）已被 .gitignore 排除，不会上传。
   别人 clone 后需要复制 .env.example 为 .env 并填入自己的 mapbox token。

2. node_modules、dist、server/node_modules 等依赖目录已排除，
   别人 clone 后执行 npm install 即可安装。

3. 项目运行需要：
   - Node.js 18+
   - SQL Server（本地 jncity 库，需初始化）
   - 联网（地图底图和高德接口）
   详见 运行说明.md

4. 如需后续更新代码：
   git add .
   git commit -m "更新说明"
   git push
