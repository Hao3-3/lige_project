# 泉城（济南）智慧出行 —— 运行说明

> 这是一个 **Vue3 + Vite 前端 + Express + SQL Server 后端** 的源码工程，
> 不能直接双击网页打开，需要按下面步骤启动。

## 一、环境准备（接收方电脑需要）

1. **Node.js 18 及以上**（自带 npm）。安装后在命令行执行 `node -v` 能看到版本号即可。
   下载：https://nodejs.org/
2. **SQL Server**（完整版或 Express 均可），要求：
   - 服务已启动，监听 **1433** 端口；
   - 开启 **SQL Server 身份验证**，启用 `sa` 账号；
   - 记住你的 `sa` 密码。
3. 电脑需要**联网**：地图底图（Mapbox）、路线规划 / 周边检索 / 路况（高德）都走在线接口。

## 二、最快启动（Windows）

1. 解压本压缩包，进入项目文件夹；
2. 先确认数据库密码：用记事本打开 `server/db.js`，把里面的
   `password: 'qiannian123456'` 改成**你本机 sa 的密码**并保存；
3. 双击 **`初始化数据库.bat`**（只需第一次运行，会自动创建 jncity 库和各张表）；
4. 双击 **`一键启动.bat`**，等待依赖安装完成后会自动打开浏览器 `http://localhost:5173`；
5. 第一次使用请在登录页点 **注册**，自己注册一个账号（需填写图形验证码），再登录。

## 三、手动命令方式（等价于上面的 bat）

```bash
# 1. 安装前端依赖（项目根目录）
npm install

# 2. 安装后端依赖
cd server
npm install
cd ..

# 3. 初始化数据库（仅首次；先改好 server/db.js 的 sa 密码）
npm run initdb
npm run initextra
npm run initevents

# 4. 启动（vite 会自动拉起后端 Express，无需另开终端）
npm run dev
```

启动成功后浏览器访问 `http://localhost:5173`。

## 四、功能与依赖关系（便于排查）

| 功能 | 是否需要 SQL Server | 是否需要联网 |
| --- | --- | --- |
| 登录 / 注册 / 验证码 | 是 | 否（本地后端） |
| 交通事件上报、收藏、历史、公告、班次后端接口 | 是 | 否（本地后端） |
| 公交 / 地铁路网图层、实时公交模拟、等高线、区县 | 否，读本地 GIS_DATA | 否 |
| 出行路线规划、周边检索、实时路况、地理编码 | 否 | 是（高德在线） |
| 地图底图 | 否 | 是（Mapbox 在线，token 在 `.env`） |

> 即使暂时不装 SQL Server，地图与本地图层、实时公交模拟等前端功能仍可加载，
> 但**登录进不去主界面**，因此完整演示仍建议按第二步配置数据库。

## 五、常见问题

- **`Port 5173 is already in use`**：5173 被占用，关掉已开的开发服务，或在任务管理器结束占用进程后重试。
- **地图区域是灰的 / 不显示底图**：检查网络，以及根目录 `.env` 里的 `VITE_TOKEN`（Mapbox token）是否还在。
- **登录一直转圈 / 提示网络错误**：SQL Server 服务没启动，或 `server/db.js` 的 sa 密码、端口不对；后端默认 `http://localhost:3000`。
- **路线规划 / 周边检索失败**：当前网络访问不了高德接口，换网络或检查代理；本项目通过 vite 的 `/amap` 代理转发，仅在 `npm run dev` 下有效。
- **不要直接双击 `index.html` 或只发 `dist`**：生产静态包缺少 `/amap`、`/api` 代理，功能会缺失。请用源码 + `npm run dev` 方式运行。
- **依赖安装慢**：可切换淘宝镜像 `npm config set registry https://registry.npmmirror.com` 后再装。

## 六、目录简介

- `src/` 前端源码（`components/BottomTools.vue` 为地图主功能）
- `server/` Express 后端与数据库脚本
- `GIS_DATA/` 本地公交 / 地铁 / 区县等 GeoJSON 数据（**不可删**）
- `.env` Mapbox token（**需要一起保留**）
- `jncity.sql` 数据库参考脚本
